1. Project Description

This project is a simple login webpage created using HTML, CSS and JavaScript. It allows a user to enter a username and password and provides basic input validation.

The webpage also has Remember Me, Forgot Password and Register options.

2. Technologies Used

- HTML – Used to create the webpage structure.
- CSS – Used for styling and layout.
- JavaScript – Used to validate user input and handle the Remember Me option.

3. Main Features

- Username and password input fields.
- Checks that the fields are not empty.
- Username must have at least 3 characters and should not contain spaces.
- Password must have at least 6 characters.
- Remember Me option uses local storage.
- Forgot Password and Register links.

4. Files Used

- "index.html" – Main login page.
- "style.css" – Contains the webpage styling.
- "app.js" – Handles validation and other actions.
- "forgot.html" – Forgot password page.
- "register.html" – Registration page.
- "images/login.webp" – Login page background image.

5. Assumptions Made

- Users should enter both username and password.
- The username should not contain spaces.
- The password should have at least 6 characters.
- This project is mainly for demonstrating frontend design and validation. It does not connect to a real database or authenticate users.

6. How to Run the Project

1. Open the project folder.
2. Locate "index.html".
3. Double-click the file to open it in a web browser.
4. Enter the username and password to test the validation.

7. Conclusion

This project helped me practice HTML, CSS and JavaScript. I also learned how to validate user input and use local storage.
